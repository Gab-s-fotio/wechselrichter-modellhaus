# Grid-Connected Inverter for a Model House

[Deutsche Version](README.de.md)

**Author:** Gaby Fotio
**University:** Technische Hochschule Mittelhessen (THM), Campus Gießen, Department MNI
**Context:** Internal project phase
**Supervisor:** Prof. Dr. Florian von Zabiensky

An STM32F407 microcontroller and a BTS7960 H-bridge turn 24 V DC into a sinusoidal 12 V RMS, 50 Hz AC voltage that powers a 12 V lamp in a model house. The microcontroller also measures the output current, voltage and frequency itself.

## Results

| Quantity | Reference measurement | STM32 | Deviation |
| --- | --- | --- | --- |
| Output voltage (RMS) | 11.801 V (oscilloscope) | 11.91 V | +0.9 % |
| Frequency | 50.072 Hz (oscilloscope) | 50.26 Hz | +0.4 % |
| Lamp current (RMS) | 0.100 A (rated value) | 0.1005 A | +0.5 % |

The calculated output was 11.88 V RMS (24 V · 0.70 / √2). The oscilloscope capture shows a clean 50 Hz sine wave (`Dokumentation/WaveForms_Ausgangsspannung_50Hz.png`).

## Hardware

| Part | Type | Role |
| --- | --- | --- |
| Microcontroller | STM32F4DISCOVERY (STM32F407VGT6, 168 MHz, VDDA = 3.0 V) | SPWM generation, measurement |
| H-bridge | BTS7960 (IBT-2 module) | Switches 24 V at 10 kHz |
| Inductor | Toroidal choke 1 mH, 5 A | LC output filter |
| Capacitor | 7 × 1 µF in parallel (planned: 10 µF MKP) | LC output filter, corner frequency 1.9 kHz |
| Load | 12 V / 1.2 W lamp, E10 socket | Consumer in the model house |
| Current sensor | ACS712-20A | Lamp current |
| Voltage sensor | ZMPT101B | Lamp voltage |
| Supply | 24 V bench power supply with current limit | Input voltage |

### Pin assignment

| STM32 pin | Function | Connected to |
| --- | --- | --- |
| PA8 | TIM1_CH1 | BTS7960 RPWM |
| PB13 | TIM1_CH1N | BTS7960 LPWM |
| PC0 | GPIO output | BTS7960 R_EN |
| PC1 | GPIO output | BTS7960 L_EN |
| PA0 | ADC1_IN0 | ACS712 OUT (recommended: via 1 kΩ) |
| PA1 | ADC1_IN1 | ZMPT101B OUT (recommended: via 1 kΩ) |

Power path: supply + → BTS7960 B+ · BTS7960 M+ → inductor → node A → ACS712 → lamp → node B → BTS7960 M−. The capacitor sits between nodes A and B. All grounds meet at a single point.

## Software

All custom code lives in `Core/Src/main.c`, inside the `USER CODE` sections generated by STM32CubeMX.

- **Sine PWM:** TIM1 runs at 168 MHz with ARR = 16,799 (10 kHz). A table of 200 duty cycles (modulation index 0.70) is copied to CCR1 by DMA (DMA2 stream 5, TIM1_UP, circular) on every timer update. The result is 50 Hz with zero CPU load. CH1 and CH1N run complementary with 119 ns dead time (bipolar SPWM).
- **Current measurement:** RMS over 100 ms, zero offset measured at start-up, sensor noise subtracted.
- **Voltage measurement:** 200 Hz digital low-pass filter (2 × first order, coefficient derived from the actual sampling interval), RMS of the AC component, calibrated against the oscilloscope (11.801 V ↔ 87.62 ADC counts).
- **Frequency measurement:** rising zero crossings with hysteresis (±30 ADC counts) and a 10 ms hold-off, time-stamped with the DWT cycle counter (168 MHz).
- **Live waveform:** every 500 µs the instantaneous voltage is written to `scopeMillivolts`, which can be plotted in the debugger with the SWV Data Trace Timeline Graph.
- **Error handling:** `Error_Handler()` disables the H-bridge and halts.

## Build and flash

1. Import the project into **STM32CubeIDE 1.18** (File → Import → Existing Projects into Workspace).
2. The HAL drivers are linked from the local STM32Cube repository (**STM32Cube FW_F4 V1.28.3**). If they are missing, open the `.ioc` file in STM32CubeMX and regenerate the code; custom code inside the `USER CODE` sections is kept.
3. Build and flash through the Discovery board's on-board ST-LINK.
4. Commissioning: first USB only (check the sensors' idle values), then 24 V with the supply's current limit set.

**Safety:** Never connect the ground clip of an earthed oscilloscope to the bridge output. Measure the output voltage with two channels against ground and take the difference.
